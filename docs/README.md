# Documentazione ed esempi

Questa cartella raccoglie le note relative al materiale di riferimento del
progetto. Per installazione e utilizzo consultare il
[README principale](../README.md), il [frontend](../frontend/README.md) e il
[backend](../backend/README.md).

## Esempi locali

La cartella [esempi](./esempi/README.md) è destinata ai documenti di
riferimento, come PDF di itinerari e matrimoni. I documenti sono esclusi da
Git; restano versionati soltanto le istruzioni e le regole di esclusione della
cartella.
